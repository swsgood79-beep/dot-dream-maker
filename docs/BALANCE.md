# 밸런스 점검 (v0.7.0)

`npm run balance` (= `npx vite-node scripts/balance-sim.ts 20`)로 다시 돌려 볼 수 있다.

## 방법
- **목표형 봇**: 엔딩 하나를 정해 두고, 부족한 스탯·적성·횟수 조건을 채우는 스케줄을 매달 짠다.
  스트레스는 50 아래로 유지하고, 필요한 콤보 가구를 사고, 매달 대화한다. 엔딩마다 20판.
  "조건충족"은 그 엔딩 조건을 만족했는지(위 티어 엔딩에 밀렸어도 포함), "획득"은 실제로 받은 엔딩.
- **캐주얼 봇**: 좋아하는 학원 2개를 자주 고르고 나머지는 무작위, 가끔 가구 구매. 500판.

| 캐주얼 플레이 엔딩 시 남은 골드 | 약 3만9천G | 약 2만6천G |

## 발견한 문제와 조정
1. **한 분야만 잘하는 아이가 백수가 됨**: INT 999에 의학·법학 적성 10인데도 방구석 한량이 나왔다.
   B등급 엔딩이 스탯 3개를 골고루 요구해서 한 분야 특화형이 받을 엔딩이 없었다.
   → B등급(06, 09, 10, 26, 31, 32, 33, 34, 49)의 보조 스탯 요구치를 낮추고 알바 횟수 8회→6회.
2. **도덕성(MOR) 700~800 요구 엔딩은 사실상 불가능**: MOR 오르는 행동이 적어 잘 키워도 650~790에서 멈춤.
   → 02 대법관 MOR 800→750, 41 용사 800→680, 42 마법소녀 700→620(ART 820→800), 43 공주 750→550(CHA 900→850, INT·ART 700→650).
3. **44 마스코트 계승자**: 가구 도감 80%에 2만G 가까이 들어 스탯 650×6을 함께 맞추기 불가능 → 전 스탯 520.
4. **다크 루트(47, 48)**: 비행 행동에 주를 쓰느라 다른 스탯이 모자람 → 47 TEC·CHA 750→700, STR 650→500 / 48 STR 750→650, CHA 700→650, INT 600→500.
5. **골드가 너무 남음**: 부모님 지원금 300/450/600 → 250/350/450G. 잘 키우는 플레이는 학원비 때문에 알바를 섞어야 한다.

## 현재 결과 (목표형 봇, 20판)
- 49종 모두 조건 달성 가능. 43 공주 85%, 44 마스코트 95%, 나머지 100%.
  (봇은 히든 조건을 다 아는 상태라 실제 플레이어에게는 훨씬 어렵다)
- 같은 티어 안에서는 기획서 규칙대로 "요구 스탯 합이 큰 엔딩"이 우선이라, 노린 엔딩보다 다른 엔딩이 나오기도 한다.
  예: 대학교수·아나운서를 노려도 경제 적성이 6 이상이면 외교관이 나옴. 도감의 조건을 보고 피해 가면 받을 수 있다.
- B등급은 A·S 조건을 만족하지 않을 때만 나오므로, 집중 플레이에서는 잘 나오지 않고 캐주얼 플레이에서 주로 나온다.
